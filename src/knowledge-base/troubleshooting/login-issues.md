# 登录问题排查指南

## 错误场景及解决方案

### 场景一：密码错误
**现象**：提示"账号或密码错误"
**解决**：
1. 点击"忘记密码"，通过手机验证码重置
2. 检查是否开启了大写锁定
3. 尝试使用微信/支付宝快捷登录
4. 如多次尝试被锁定，30 分钟后自动解锁

### 场景二：验证码收不到
**现象**：点击获取验证码后无响应
**解决**：
1. 检查手机信号是否正常
2. 确认手机号输入是否正确
3. 查看短信是否被拦截（垃圾短信/骚扰拦截）
4. 等待 60 秒后重新获取
5. 尝试切换语音验证码

### 场景三：账号被锁定
**现象**：提示"账号已锁定"
**原因**：多次输入错误密码
**解决**：
1. 等待 30 分钟自动解锁
2. 使用"忘记密码"重置密码后自动解锁
3. 联系客服人工解锁

### 场景四：第三方登录失败
**现象**：微信/支付宝登录提示授权失败
**解决**：
1. 确认第三方账号已实名
2. 清除微信/支付宝缓存后重试
3. 取消授权后重新绑定
4. 使用手机号+密码方式备用登录

### 场景五：账号被异地登录
**现象**：收到异地登录提醒
**解决**：
1. 立即修改密码
2. 在"账号安全"中查看登录设备
3. 移除陌生设备
4. 联系客服确认账号安全状态

## 通用排查步骤
1. 切换登录方式（密码→验证码→第三方）
2. 清除 APP 缓存或重新安装
3. 切换网络环境
4. 更新 APP 至最新版本
5. 如以上均无效，联系在线客服

## 客服处理流程
1. 验证用户身份（手机号 + 验证码 + 其他信息）
2. 确认账号状态（正常/锁定/冻结）
3. 根据情况协助重置密码或解冻账号
4. 如有安全风险，建议开启二次验证
