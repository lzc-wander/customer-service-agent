# 支付失败排查指南

## 错误场景及解决方案

### 场景一：银行卡余额/额度不足
**现象**：提示"支付失败，余额不足"
**解决**：
1. 确认卡内余额或信用卡额度是否充足
2. 更换其他银行卡或支付方式
3. 拆分订单金额后分批支付

### 场景二：银行风控拦截
**现象**：已扣款但订单未支付成功
**解决**：
1. 联系发卡行确认是否触发风控
2. 银行通常 1-3 个工作日自动解冻退款
3. 建议更换支付方式或使用小额分笔支付

### 场景三：网络超时
**现象**：支付页面加载中，最终提示超时
**解决**：
1. 检查网络连接，切换 Wi-Fi / 移动网络
2. 重新进入支付页面
3. 如已扣款但订单未生成，联系客服处理

### 场景四：支付限额
**现象**：提示"超过单笔/单日限额"
**解决**：
1. 银行卡单笔限额通常为 5000-10000 元
2. 可分批支付或更换其他银行卡
3. 联系银行临时提高限额

## 通用排查步骤
1. 刷新页面重试支付
2. 切换支付方式（微信→支付宝→银行卡）
3. 清除浏览器缓存或换浏览器
4. 使用 APP 端代替网页端支付
5. 如以上均无效，联系在线客服

## 客服处理流程
1. 确认用户订单号、支付金额、支付方式
2. 核对支付状态（银行端 vs 系统端）
3. 如银行已扣款系统未到账 → 登记工单，财务 1-3 个工作日核对
4. 如系统超时未支付 → 协助用户重新发起支付
